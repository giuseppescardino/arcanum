# Arcanum — browser extension

Extension for Chrome, Opera and Safari that, while you browse:

- **fills** saved logins: an Arcanum icon appears in login fields, and its menu lists the logins saved for the current site;
- **suggests** a generated password in sign-up and change-password forms, filling both the password and its confirmation;
- **saves** new logins, or updates a changed password, after you submit a form (banner "Salvare in Arcanum…?" / "Aggiornare…?").

It holds no vault data and no keys: it asks the **Arcanum desktop app** (macOS, Windows or Linux), which must be running and unlocked. Closing the app's window leaves it running in the system tray, so the extension keeps working; choose **Quit** from the tray menu to stop it (see *Impostazioni* → **Desktop**, where you can also start Arcanum at login). The design and threat model are in [docs/SECURITY.md](../docs/SECURITY.md#browser-extension) and [the design spec](../docs/superpowers/specs/2026-11-11-browser-extension-design.md).

Requirements: Chrome or Opera 133+ (X25519 in WebCrypto), Safari 17+.

## Layout

| Path | Contents |
|---|---|
| `src/` | What ships: `manifest.json`, `background.js` (the only part that talks to the app), `content/ui.js` (inline icon, menu, save banner), `popup/`, `lib/` (shared classic scripts) |
| `scripts/package.sh` | Builds the Chromium zip and the Safari app (see Packages) |
| `test/` | `node --test` unit tests, `vectors.json` (written by `core/arcanum-bridge`, see below), sample pages in `test/pages/` |
| `safari/` | Xcode project that wraps `src/` as a Safari Web Extension (generated by `safari-web-extension-converter`, references `src/` without copying) |

All scripts are classic scripts (no `import`/`export`) sharing `globalThis.Arcanum`. Safari runs neither module service workers nor module content scripts, and loading modules from a content script would make files web-accessible to pages. There is no build step.

## Install (development)

### Chrome / Opera

1. Open `chrome://extensions` (Opera: `opera://extensions`) and turn on **Developer mode**.
2. **Load unpacked** → select `extension/src`.

### Safari (macOS)

```bash
open "extension/safari/Arcanum Safari/Arcanum Safari.xcodeproj"
```

1. Set your team on both targets (*Signing & Capabilities*), or build ad-hoc signed with `xcodebuild … CODE_SIGN_IDENTITY=- DEVELOPMENT_TEAM=`.
2. Run the "Arcanum Safari" scheme once: it registers the extension.
3. Without a team, allow unsigned extensions in Safari: *Settings → Advanced → Show features for web developers*, then *Develop → Allow Unsigned Extensions* (this has to be repeated after every Safari restart).
4. *Safari → Settings → Extensions* → enable **Arcanum** and allow it on all websites.

## Packages

`scripts/package.sh` builds what CI publishes (names carry the version from `src/manifest.json`; default output `extension/dist/`):

```bash
scripts/package.sh chromium   # Arcanum-extension-chromium-<version>.zip
scripts/package.sh safari     # Arcanum-Safari-<version>.zip (macOS + Xcode)
```

Both pipelines (GitHub Actions `ci.yml`, Azure `azure-pipelines.yml`) run them and publish the artifacts `extension-chromium` and `extension-safari`.

- **Chrome / Opera / Edge**: unzip, then **Load unpacked** on the unzipped folder (Developer mode). The same zip is what the Chrome Web Store, Opera Add-ons and Edge Add-ons take.
- **Safari**: unzip, open `Arcanum Safari.app` once, then follow steps 3–4 of the Safari install above. The app is ad-hoc signed, so Safari runs it only with **Allow Unsigned Extensions**; without it you need a Developer ID signature and notarization.

The extension needs the Arcanum desktop app, which runs on macOS, Windows and Linux.

## Connect to the app

1. In Arcanum (desktop), open *Impostazioni* → **Browser collegati** → **Collega browser**. Pairing stays open for 2 minutes.
2. In the browser, click the Arcanum toolbar button → **Collega**. The popup shows a 6-digit code.
3. Type that code in the app's dialog and press **Collega**. The app never shows the code itself; after three wrong codes the pairing is rejected.

To disconnect a browser, use **Revoca** in the same screen.

## Tests

```bash
cd extension && npm test
```

`test/crypto.test.js` checks that the WebCrypto code reproduces vectors produced by the Rust core. After changing the protocol in `core/arcanum-bridge`, regenerate them:

```bash
cd core && UPDATE_VECTORS=1 cargo test -p arcanum-bridge --test vectors
```

After editing files under `src/`, press **Reload** on the extension's card: the background keeps its imported scripts cached until the extension reloads. In Safari, quit Safari (⌘Q) before rebuilding the wrapper and reopen it afterwards: rebuilding replaces the bundle under the running extension, and Safari then stops loading its background ("Connessione…" in the popup, an empty inline menu) until it restarts.

To try fill and save by hand, serve the sample pages and open `http://localhost:8765/login.html` or `signup.html`:

```bash
cd extension/test/pages && python3 -m http.server 8765 --bind 127.0.0.1
```
